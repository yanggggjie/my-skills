# use case

## 获取尚未在本地的 GitHub 仓库
目标：得到可供只读探索的 GitHub 仓库本地路径
操作：
- 从 GitHub URL 或用户输入中识别 `owner/repo`
- 在 `~/.gh-repos/<owner>/<repo>` 不存在时用 `gh repo clone` 浅克隆
- 检查目标目录存在
可观察结果：返回已存在仓库目录的绝对路径

## 复用已有仓库
目标：避免重复克隆已经存在的仓库
操作：
- 计算 `~/.gh-repos/<owner>/<repo>`
- 发现目录已经存在时直接使用，不主动拉取
可观察结果：返回原有目录的绝对路径，仓库未被更新或重建

## 探索仓库内容
目标：以本地仓库为唯一文件依据完成阅读、搜索和分析
操作：
- 只在返回的仓库路径下读取和搜索文件
- 对未找到的信息明确说明未找到
可观察结果：关于仓库文件的结论可追溯到该目录

## 更新已有仓库
目标：在用户明确要求时将已有浅克隆更新到最新状态
操作：
- 在目标仓库运行 `git pull --ff-only`
- 检查命令成功
可观察结果：仓库已快进更新或确认已是最新，并返回同一绝对路径
