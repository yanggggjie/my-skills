# use case

一条 use case：完成一个具体目标而进行的一组操作，并得到可观察结果。

## 为一块内容选定表达形式
目标：只回答这块材料用哪种 md 结构
操作：
- 对照「材料是 / 用 / 不要用」表选定
- 能说出为什么不用「不要用」那一列
可观察结果：每一块都有选定的结构；不必写成篇

## 按规范写出正文
目标：把已选定的结构落成漂亮的 md
操作：
- 标题只用两级，默认 `# 1` / `## 1.1`
- 一块意思一段
- 并列用 `-`；一条线性步骤用数字；非线性流程用 mermaid；对照用表；词条用 `**词**` 加下一行解释；代码用围栏或行内；待办用 `- [ ]`；原话用 `>`；少量词用粗体
可观察结果：每块都能对上选定的那一行；没有 `###`；没有用一段话代替列表、表格或图

## 把 md 写漂亮
目标：把新材料或已有 md 收成漂亮的正文
操作：
- 新材料：先为每块选定结构，再按规范写出
- 已有 md：先核对每块；只改正不符合的；已经符合的不要重写
- 写完用任务列表自检
可观察结果：交出一份 md；读起来能按块扫，不必从一段散文里抠结构
