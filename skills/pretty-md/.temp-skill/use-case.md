# use case

## 简化并重构 Markdown

目标：在信息不减少的前提下，把已有 Markdown 整理成简洁的三层内容树。

操作：

- 保存并重读原文，标记不得改写的内容。
- 删除重复、压缩长句、合并同义内容。
- 按“方面—具体方法—具体内容”重组全文。

可观察结果：文档只包含一个根标题、带编号的方面和具体方法，且原文信息完整保留。

## 选择 Markdown 格式

目标：让每类内容使用固定且易读的 Markdown 形式。

操作：

- 根据顺序、分支、验收、对比、层级和风险选择列表、Mermaid、checklist、表格、文件树或提示块。
- 对代码、引用、链接、术语、键值和示例使用规定格式。

可观察结果：每个具体内容块都符合对应格式的触发条件和使用规则。

## 检查内容保真

目标：确认简化和重构没有改变原意。

操作：

- 对照原文检查事实、观点、条件、例外、要求强度和字面内容。
- 对无法唯一确定的冲突或歧义保留原文并标记待确认。

可观察结果：文档没有遗漏信息，也没有新增原文不存在的事实或结论。
